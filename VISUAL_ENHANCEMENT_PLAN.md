## 📐 IMAGE GUIDELINES & BEST PRACTICES

### General Requirements for ALL Images

1. **Resolution:**
   - Minimum: 1200px on longest side
   - Preferred: 1920px or higher
   - Print-quality: 300 DPI if planning printed materials

2. **File Format:**
   - Photos: JPG (preferred)
   - Logos/Graphics with transparency: PNG
   - Icons: SVG (preferred) or PNG
   - Complex graphics: SVG or high-res PNG

3. **File Size:**
   - Hero images: Max 800KB
   - Standard images: Max 500KB
   - Thumbnails: Max 200KB
   - Logos: Max 200KB
   - *Compress using tools like TinyPNG or JPEGoptim*

4. **Aspect Ratios:**
   - Hero backgrounds: 16:9 (1920x1080)
   - Card images: 4:3 (1200x900) or 16:9
   - Portrait photos: 1:1 (800x800) or 3:4
   - Project thumbnails: 4:3 or 16:9
   - Logos: Original aspect ratio

5. **Quality Checklist:**
   - [ ] Good lighting (not too dark or overexposed)
   - [ ] In focus (no blur)
   - [ ] High resolution (not pixelated)
   - [ ] Authentic (real project photos, not stock)
   - [ ] Contextual (shows actual ESDU work)
   - [ ] Professional (well-composed)

6. **Legal/Ethics:**
   - [ ] Consent forms signed for people in photos
   - [ ] Permission obtained for logos
   - [ ] No copyrighted material without license
   - [ ] Respectful representation of communities
   - [ ] Privacy considerations for beneficiaries

## 📁 FILE NAMING CONVENTION

**Use this standardized naming:**

```
[category]-[descriptor]-[number].[extension]

Examples:
- timeline-1996-founding.jpg
- project-medwise.jpg
- team-member-01.jpg
- logo-donor-fao.png
- fieldwork-agriculture-05.jpg
- before-waste-01.jpg
- after-waste-01.jpg
```

**Rules:**
- All lowercase
- Hyphens (not spaces or underscores)
- Descriptive but concise
- Sequential numbering (01, 02, 03...)
- Clear before/after pairing
